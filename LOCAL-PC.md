# Локальная разработка и отдельная лаборатория Windows AD

## Автономный CLI на компьютере

Python 3.12; установка Windows/POSIX и удаление: [INSTALL](INSTALL.md). Проверить safe/risky/incomplete из исходного архива, коды 0/1/3, испорченный ввод 2, новый output, UTF-8. Hosted Windows CI подтверждает переносимый CLI, не права или API AD. Частные файлы вне checkout с локальным ACL/шифрованием и сроком удаления.

## Реальная инфраструктурная приёмка

Отдельная сеть без production маршрутов, лес lab.example.test; DC1/DC2 Windows Server 2022 AD DS/DNS, CA1 AD CS, MEMBER1 SMB/сервисы, MGMT1 PowerShell 5.1+RSAT. Владелец предоставляет образы/лицензии и бюджет, а задача не создаёт платные ресурсы. Начальный план 5 VM ×2 vCPU/4 GiB, диски от 60 GiB; уточнить по нагрузке. Поддержка 2019/2025 пока не подтверждена.

Отдельный администратор настраивает safe/risky/denied сценарии и контрольные точки; AuditReader получает только утверждённые read-права. Credentials вводятся средствами Windows, не Git/чатом. До и после проверить объекты/ACL/GPO/CA. Отказ доступа не должен вызывать повышение прав или ложный pass. Нагрузка, TLS/подпись, страницы, частичная видимость и междоменные границы проверяются отдельно.

MVP не собирает данные: оператор независимо подтверждает нормализованные facts, хранит private evidence, сравнивает CLI с эталоном. Полный набор шагов и примеры read-only команд: [docs/lab.md](docs/lab.md). Наличие backup не доказывает restore; отдельный разрешённый drill в изолированном клоне выполняет владелец восстановления.

## Статус

Все реальные Tier 0/AD CS/ACL/SPN/gMSA/NTLM/LDAP/SMB/event/recovery сценарии: **НЕ ВЫПОЛНЕНО / not_run**. Сборщик отсутствует. На каждую проверку нужны дата, версии ОС/модулей/правил, scope, expected/actual, private evidence ID, reviewer и хеш снимка. Synthetic/ordinary Windows CI не закрывает эту приёмку.
