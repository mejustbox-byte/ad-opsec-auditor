# Подробная модель угроз

Активы: целостность AD/CA/GPO, учётные данные, частная топология/ACL/журналы, достоверность выводов и доступность DC. Границы: оператор → будущий Windows-сборщик → службы AD; частное хранилище → автономный анализатор → читатель отчёта; отдельно синтетические примеры → публичный CI. Реальные данные не пересекают публичную границу.

Противники: вредоносные объекты каталога/JSON, ошибающийся оператор, скомпрометированная зависимость/PR/узел и неразрешённый читатель отчёта. Операции чтения будущего сборщика тоже создадут нагрузку и сетевые события.

| ID | Угроза | Контроль | Проверка и остаточный риск |
| --- | --- | --- | --- |
| TM-01 | Подмена DC/CA или снижение защиты LDAP | Доверенные узлы, Kerberos/LDAPS/подпись, без отключения TLS | Будущая Windows проверка неверного сертификата; компрометация доверия остаётся риском |
| TM-02 | Скрытая запись через API | Разрешённый список чтения, проверка каждого источника, запрет выдачи сертификатов и изменений | Трасса/контроль AD до и после; пока not_run |
| TM-03 | Выполнение строк/HTML | Нет eval/Invoke-Expression, сеть отсутствует, безопасный Markdown, ограничения JSON | Отрицательные примеры и экранирование проверяются; читатель JSON тоже должен безопасно отображать текст |
| TM-04 | Утечка секретов/топологии | Частное хранилище, запрет exports в Git, синтетические примеры, scan и review | Scan не распознаёт все секреты; оператор может неверно перенаправить stdout |
| TM-05 | Потеря данных даёт ложный pass | Полнота и ссылки обязательны; missing/partial → unknown | Тесты отрицательных данных; истинность complete заявления не подтверждается |
| TM-06 | Перегрузка DC | Будущие ограничения области/страниц/времени/параллелизма | Нагрузочный стенд пока not_run; текущий CLI к DC не обращается |
| TM-07 | Подмена снимка/правила/выпуска | Версии, хеш точных байтов, закреплённые зависимости, immutable tag, download verification | Хеш не подтверждает подлинность источника или автора |
| TM-08 | Кража прав оператора | Минимальные read-права будущего сборщика, доверенный Windows-host | Реальная проверка прав пока not_run; endpoint остаётся границей доверия |
| TM-09 | Вредоносный PR/зависимость | Нет secrets в CI, SHA Actions, runtime без сторонних пакетов, manual main publisher | Право contents:write только publisher; maintainer/host всё ещё доверенные |
| TM-10 | Ложная уверенность в восстановлении | Разделение runbook/backup/успешного датированного учения | CLI только фиксирует заявленные факты; реальный drill not_run |

Запрещены DCSync, чтение NTDS/SAM/LSASS, passwords gMSA, hashes/tickets, private keys CA, relay/coercion/spraying, certificate enrollment, удалённое внедрение кода, правки политик и restore аудитором. При неожиданной записи или выходе за область будущий сбор останавливается; расследует владелец стенда. При утечке ограничить доступ и отозвать credential; удаление файла не очищает историю.

MVP ограничивает ввод 2 MiB/16 уровней, типы/строки/массивы, отвергает duplicate keys/нечисловые значения и не выводит ошибочный ввод. Evidence refs не открываются. Output O_EXCL, POSIX 0600; parent ACL/шифрование/retention вне функций CLI. Полнота, источник, реальные API, безопасность сбора и recovery не доказаны.
