# ADR-0001: сбор данных Windows и автономный анализ

Дата: 2026-10-09. Статус: принято; уточнено [ADR-0002](0002-offline-mvp.md).

## Контекст

Нужны чтение данных AD без эксплуатации и секретов, собственные средства Windows для дескрипторов безопасности и RSAT, переносимость анализа и воспроизводимые синтетические тесты. Исходный репозиторий содержал только README. Облако Linux не заменяет реальный Windows-стенд.

## Решение

Будущий сборщик: Windows PowerShell 5.1, RSAT ActiveDirectory/GroupPolicy и явно разрешённые операции чтения Windows API. Причина: встроенная аутентификация и доступ к административным модулям чтения. AD CS, действующие политики и журналы требуют отдельных прототипов и прав. Наличие RSAT не доказывает готовность этих источников; совместимость PowerShell 7/Linux не заявляется.

Автономный анализатор: Python 3.12, версионированный JSON, чистые правила без сети. Стандартная библиотека обеспечивает разбор JSON и тесты; внешних зависимостей во время работы нет. Интерфейс HTML, база данных, служба и контейнеры пока не нужны. Инструменты сборки и эталонной проверки схемы закреплены по версиям и хешам.

## Альтернативы и последствия

C#/.NET: строгие типы и Windows API, но сложнее начальная сборка и доставка; пересмотреть при недостатке API или производительности PowerShell. PowerShell для всего анализа: один язык, но сложнее отделить Windows-модули от переносимых проверок. Сборщик Python LDAP: переносим, но не покрывает действующие политики и события Windows без дополнительных библиотек. Инструменты эксплуатации не подходят ограничениям.

Два разных этапа требуют явного контракта и Windows-стенда. Работа только чтением доказывается проверкой API и лабораторией, а не выбором языка. В текущем предварительном выпуске реализован лишь автономный анализ; сборщик и реальные платформенные проверки остаются not_run.
