# ADR-0002: автономный MVP на основе свидетельств

Дата: 2026-10-09. Статус: принято. Дополняет ADR-0001.

Windows AD стенд недоступен. Решение: пригодный автономный предварительный выпуск, без непроверенного сборщика и без утверждения, что синтетические тесты проверили AD.

Python >=3.12,<3.13, без зависимостей во время работы. Схема JSON Draft 2020-12 описывает узкий контракт; встроенный валидатор поддерживает используемые ограничения. Схема создаётся из одного декларативного источника и входит в пакет. Отдельная сверка с jsonschema проверяет согласованность. Правила используют только фиксированные поля; произвольные выражения и скрипты запрещены.

Публичные примеры имеют synthetic=true. Частный ввод может иметь synthetic=false, но происхождение остаётся непроверенным. Ссылки на свидетельства — логические ID; файлы и URL по ним не открываются. Нормализованные счётчики и признаки ускоряют оценку, но не заменяют вычисление прав ACL, доказательства эксплуатации CA, получение действующих политик или восстановление леса.

Сборка и проверка схемы используют закреплённые версии и SHA256. Поставляются wheel, исходный архив и переносимый zipapp. Метаданные упаковки нормализованы; SHA256SUMS обеспечивает сравнение целостности, но не подпись владельца. Публикация — вручную запускаемый Actions с неизменным тегом, проверкой исходного commit и существующего draft.

Набор правил baseline-v1 имеет фиксированные пороги. Изменения политики потребуют пересмотра версий. Выпуск 0.1.0a2 переводит пользовательские тексты на русский без изменения ключей JSON и логики. Тег AD v0.1.0a2; старый v0.1.0a1 сохранён. Реальные Windows проверки остаются not_run.
