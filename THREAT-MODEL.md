# Модель угроз и остаточные риски

Активы: целостность AD/CA/GPO, учётные данные оператора, конфиденциальность снимков/топологии, достоверность выводов, доступность DC. Границы: недоверенный JSON → анализатор → частный отчёт; доверенный оператор подтверждает факты. Публичные синтетические данные отдельно от реального стенда. Будущий сборщик добавит границы Windows → AD, но сейчас отсутствует.

| Угроза | Контроль MVP | Остаточный риск / проверка |
| --- | --- | --- |
| Вредоносный/слишком большой JSON | 2 MiB, глубина 16, строгие поля/типы/числа/строки, duplicate key rejection | Отрицательные тесты; загрузка допустимого входа расходует ограниченную память |
| Выполнение строки или HTML | Нет eval/команд/сети; Markdown экранируется; ссылки лишь ID | Недоверенный читатель отчёта должен также безопасно отображать JSON |
| Ложный pass из отсутствия данных | Обязательные факты/ссылки/complete; unknown/not_run | Полнота и истинность заявления оператора независимо не доказываются |
| Подмена свидетельств | Хеш точных входных байтов и версии | Хеш не подпись; нужен доверенный частный источник и review |
| Утечка в Git/CI | Запрет реальных exports, игнорирование частных каталогов, синтетические примеры, шаблонный scan и ручная проверка | Scan не распознаёт все секреты; stdout может быть неверно перенаправлен оператором |
| Перезапись/публикация отчёта | O_EXCL, новый файл, POSIX 0600 | Родительский ACL/шифрование/retention — обязанность оператора; Windows проверяется отдельно |
| Подмена зависимости/выпуска | Закреплённые версии/хеши, SHA Actions, неизменный tag/commit, проверка скачанных assets | Нет подписи владельца и независимого внешнего аудита |
| Избыточные права публикации | Только manual main, build read-only, publisher contents:write, штатный ephemeral GITHUB_TOKEN | Доверенным workflow maintainers принадлежит управление репозиторием |

Будущие угрозы подмены DC/TLS, случайной записи, перегрузки DC и кражи избыточных прав требуют отдельной Windows-трассы; не считать их проверенными сейчас. Recovery document не доказывает успешный restore. [Подробная модель и ID TM-01…TM-10](docs/threat-model.md), [стенд](LOCAL-PC.md), [сообщение об уязвимости](SECURITY.md).
